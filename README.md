Entry for the make.fun bounty **"What the Elevator Would Say"**
(`u-eager-stork-81-9647-what-the-elevator-would-say-90844958`).

The program writes one line — the funniest thing an elevator would say if it
could talk, in the elevator's own voice — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Node.js 22.18+ (stdlib only, no dependencies). The entry is a single line of
at most 120 characters.

## The line

> Going down. Relax, I heard everything you said about your boss on floor nine, and I agree.
